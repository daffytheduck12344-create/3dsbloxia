3DSBlox

A small, playable Roblox-inspired 3DS-style building prototype

Prototype · browser build

Play: WASD / arrow keys to move, Space or A to jump, drag the lower workspace to orbit, and tap the lower screen's ◀/▶ controls. Build: tap the Studio toggle, select a color/tool, then tap the workspace to place a block. Select a hotbar tool to equip it. Import supports basic .rbxlx XML parts; native binary .rbxl and actual 3DS hardware rendering are not implemented yet.
